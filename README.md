## 🚀 Live Demo & Deployment

This project is pre-configured for instant deployment on [Netlify](https://www.netlify.com/).

### Deploy via Netlify CLI:
```bash
# 1. Install Netlify CLI
npm install -g netlify-cli

# 2. Deploy to preview
netlify deploy

# 3. Deploy to production
netlify deploy --prod
```

### Deploy via Git / Netlify Web Dashboard:
1. Connect your repository to Netlify.
2. Build Settings are automatically configured from `netlify.toml`:
   - **Build Command:** `npm run build`
   - **Publish Directory:** `dist`
   - **Node Version:** `20`
3. Click **Deploy Site**.

## 🛠️ Local Development

```bash
# Install dependencies

npm run build

# Preview production build locally
npm run preview
```
